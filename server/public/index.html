Cómo instalar

  1. Toca Descargar APK desde tu Android.
  2. Si el sistema lo pide, permite instalar apps desconocidas para el navegador.
  3. Abre el archivo descargado y toca Instalar.
  4. Las actualizaciones llegan solas desde la app (Ajustes → Buscar actualizaciones).
